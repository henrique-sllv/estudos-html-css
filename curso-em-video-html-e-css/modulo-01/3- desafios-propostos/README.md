## 🎯 Desafios Desenvolvidos

### 1. Minhas Redes Sociais
Uma página de apresentação pessoal 
* **O que foi praticado:**
  - Inserção de favicon e título da página.
  - Uso de imagens locais e caminhos relativos (`<img>`).
  - Criação de listas não ordenadas (`<ul>`, `<li>`) para agrupamento de links.
  - Uso de âncoras (`<a>`) com os atributos `target="_blank"` e `rel="external"` para abertura segura em novas abas.

### 2. Lista de Abreviações e Códigos (`LISTA ABBR`)
Um guia/dicionário interativo catalogando tags e comandos úteis do desenvolvimento web.
* **O que foi praticado:**
  - Uso de listas ordenadas com numeração romana (`<ol type="i">`).
  - Emprego da tag semântica `<abbr>` combinada com o atributo `title` para criar dicas flutuantes ao passar o mouse.
