# 5 Desafio Proposto

---

## Descrição do Desafio
Desenvolver um mini site contendo uma grade com **4 vídeos**. 

### Requisitos das Páginas Internas:
Ao clicar em qualquer vídeo da grade principal, o usuário será redirecionado para uma nova página contendo:
* **Prévia do vídeo:** Player incorporado para o usuário assistir sem sair do site.
* **Link direto para o YouTube:** Link externo configurado para abrir em uma nova aba (`target="_blank"`).
* **Botão de voltar:** Botão ou imagem que redireciona o usuário de volta para a página principal.
