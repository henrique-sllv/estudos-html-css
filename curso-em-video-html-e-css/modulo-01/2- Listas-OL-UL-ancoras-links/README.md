# 🖼️ Prática: Listas OL/UL, Âncoras e Links

---

## 🎯 O que foi praticado nesta etapa

- **Listas OL/UL:** Listagem de itens usando as tags `<ol>` e `<ul>` e seus diferentes tipos de marcação (`type`).
- **Listas mistas e de definição:** Criação de estruturas aninhadas (juntando listas) e listas com termos e definições (`<dl>`, `<dt>`, `<dd>`).
- **Âncoras:** Adicionando links externos por meio de âncoras (`<a>`).
- **Atributos target e rel:** Utilizando atributos para abrir links em novas abas de forma segura `<target="">`, `<rel="">`.
