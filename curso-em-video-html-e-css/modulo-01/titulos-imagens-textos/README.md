# 🖼️ Prática: Títulos, Imagens e Textos

---

## 🎯 O que foi praticado nesta etapa

- **Hierarquia de Títulos:** Aplicação da tag `<h1>` para o título principal da página e `<h2>...<h6>` para subdividir as seções.
- **Inserção de Imagem Local:** Carregamento de arquivo do gerenciador local no formato moderno e otimizado `.webp`.
- **Inserção de Imagem Externa:** Carregamento de mídia remota via URL direta.
- **Atributos de Imagem:** Configuração de acessibilidade com o atributo `alt` e controle de exibição com `width` e `height`.
- **Favicon do Site:** Adição do ícone da aba do navegador via `<link rel="shortcut icon">`.
- **Comentários no Código:** Organização do documento HTML com comentários explicativos para marcar cada bloco de estudo.

## 📝 Formatações de Texto
- **Negrito e itálico:** Formatação correta de texto de forma semântica utilizando as tags `<strong>` e `<em>`.
- **Texto marcado:** Utilização da tag `<mark>` e a troca de cores com `<style>`.
- **Texto grande e texto pequeno:** Mudança de tamanho de textos utilizando `<big>` e `<small>`.
- **Texto inserido e excluído:** Utilização das tags `<ins>` e `<del>`.
- **Código-fonte:** Tag `<code>` para facilitar a leitura de blocos de código.
- **Código pré-formatado:** Utilização de `<pre>` para mostrar exatamente o que foi escrito.
- **Citação simples e completa:** Citações com as tags `<q>` e `<blockquote>`.
