## 📌 Sobre o Projeto

Este repositório foi criado para documentar minha evolução prática em desenvolvimento web. Aqui organizo conteúdos teóricos, exercícios práticos e projetos que fixam os aprendizados obtidos ao longo dos meus estudos.

---

## 📂 Estrutura 

Para manter os estudos limpos e organizados, divido o repositório considerando o formato de cada curso:

* **Para cursos divididos em módulos:** Cada módulo armazena os seus respectivos arquivos de conteúdo prático. O **projeto final** fica localizado na raiz da pasta do curso, unindo e aplicando tudo o que foi aprendido ao longo de todos os módulos.
* **Para cursos sem divisão de módulos:** A pasta do curso concentra os arquivos de conteúdo direto, acompanhada de um **projeto final** focado no tema abordado.

Veja abaixo o modelo visual de como os diretórios são organizados:

```
curso-com-modulos/
├── 📁 modulo-01/
│   ├── 📁 conteudo/
│   │   └── 📄
│   └── 📁 conteudo/
│       └── 📄
├── 📁 modulo-02/
│   ├── 📁 conteudo/
│   │   └── 📄
│   └── 📁 conteudo/
│       └── 📄
├── 📁 projeto-final/ (Agrega todos os módulos)
└── 📄 README.md

curso-sem-modulos/
├── 📁 conteudo/
│   └── 📄
├── 📁 conteudo/
│   └── 📄
├── 📁 projeto-final/
│   └── 📄
└── 📄 README.md
```
