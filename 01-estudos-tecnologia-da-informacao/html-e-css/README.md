## 📂 Organização dos Conteúdos

Os arquivos desta pasta são divididos por **curso ou material de estudo**, respeitando o formato original de cada conteúdo:

- **Materiais com módulos:** Organizados em subpastas sequenciais (ex: `modulo-01/`, `modulo-02/`), contendo os exercícios de cada aula e um mini projeto de encerramento por módulo.
- **Materiais sem módulos:** Organizados diretamente por assunto ou tema, reunindo os exercícios práticos e um mini projeto final para consolidar o aprendizado.
