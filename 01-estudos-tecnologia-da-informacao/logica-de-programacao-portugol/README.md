# 🌏Visualg-lógica-de-programação
Codigos aprendidos durante o aprendizado de algoritmos 
### 📌 Sobre o Projeto
Este é um projeto desenvolvido em **Visualg (Portugol)** com o objetivo de praticar e fixar os conceitos fundamentais de **Lógica de Programação**, como manipulação de variáveis, estruturas condicionais, de repetição e vetores/matrizes. 

O sistema simula um **Organizador de Dívidas** básico de console, focado no fluxo inicial de cadastro e consulta de registros.

---

### ⚙️ Funcionalidades Atuais
* **Cadastro de Dívidas:** Permite registrar novas dívidas informando os dados necessários.
* **Listagem de Dívidas:** Exibe todas as dívidas cadastradas de forma organizada no console.

> *Nota: Este projeto foi criado como um exercício prático para fixação da lógica de programação. Por esse motivo, funcionalidades avançadas de gerenciamento (como exclusão e baixa/pagamento de dívidas) não foram implementadas nesta versão inicial.*
